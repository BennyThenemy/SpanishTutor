# First lesson — plan

The first lesson is the same for every learner: a fixed on-screen placement, then a live call with
Lucía. Nothing in the placement is generated by AI. The call is live AI, but it follows a fixed plan
and uses what the placement found.

```
Welcome
  └─ Q1 How much Spanish do you know?
  └─ Q2 Where did you learn so far?
        ├─ "A few words"      → Vocab bubbles (from section 1) → Grammar ladder (from rung 1)
        └─ "I want to speak"  → Grammar ladder (from rung 5; fail rung 5 → restart at rung 1)
  └─ Results (friendly summary)
        ├─ Call now   → First call with Lucía
        └─ Call later → sets "Next call" on Home
```

## 1. Opening questions

**Q1: How much Spanish do you know?**
1. I know a few words
2. I know it well, but I want to practice speaking

**Q2: Where have you learned Spanish so far?**
1. Duolingo
2. Another learning app
3. Neither / a class / on my own

Both questions are asked on both paths. Q2 doesn't change the test. It is saved to the profile and
changes the wording of the results (see §4).

## 2. Vocabulary bubbles (path 1 only)

- The words come from `db/setup-words.sql` (871 entries from the Duolingo section list).
  The words shown are the rows with `in_placement = 1`.
- There is **one screen per Duolingo section, with 12 bubbles each**: sections 1, 2, 3, 4, 5, 7, 8.
  That makes 84 words in all. The source has no data for section 6, so the test jumps from 5 to 7.
- The learner taps every word they know. Each screen also has an **"I don't know any of these"**
  button, which counts as 0 taps.
- **Stop rule:** fewer than 4 of 12 taps (under 30%) ends the vocab part.
- **Result:** `vocabSection` = the last section passed (0 if section 1 was not passed).
- **No fake words.** Taps are taken at face value.
- Words **not tapped**, on screens the learner actually saw, go into the learner's vocabulary list.
  Words on screens they never reached are not added.

## 3. Grammar ladder (both paths)

All 24 items (8 rungs × 3) are in `db/setup-grammar.sql`. Each item has 4 options plus
**"I don't know"**, which the app adds and counts as wrong.

- **Stop rule:** 0–1 correct out of 3 ends the ladder. `grammarRung` = the highest rung passed.
- Path 1 starts at rung 1.
- Path 2 starts at the rung marked `speaking_path_start` (rung 5 in Spanish). If they fail it, they
  restart at rung 1 and continue from there.

| Rung | Topic | Example |
|---|---|---|
| 1 | Present, regular -ar/-er/-ir | Nosotros (cocinamos / cocinan / cocinas / cocino) arroz. |
| 2 | ser vs. estar | Mi hermana (es / está) cansada hoy. |
| 3 | Present, irregular and stem-changing | Yo no (sabo / sé / sabe / sabes) la respuesta. |
| 4 | Near future: ir a + infinitive | Mañana yo (voy a / vas a / voy / ir a) estudiar. |
| 5 | gustar and object pronouns | A ellos (le / les / los / se) gusta el café. |
| 6 | Preterite | Ayer nosotros (fueron / vamos / fuimos / iremos) al cine y vimos una película. |
| 7 | Preterite vs. imperfect | Cuando era niño, (jugué / jugaba) en el parque todos los días. |
| 8 | Present subjunctive | Quiero que tú (vienes / vengas / vendrás / venir) mañana. |

Grammar gaps are **not saved** anywhere for now.

## 4. Results screen

- A friendly summary. **No CEFR label is shown.** For example: *"You know 31 of our core words, and
  you're solid on the present tense. Next up: the past tense."*
- If Q2 = Duolingo, it also says roughly where they are in the course: *"about Duolingo section 3"*.
- The CEFR level is internal and fills the profile's `level` field.
- **Call now** (primary) starts the first call. **Call later** sets the time shown as "Next call" on Home.

**Retakes and interruptions**
- **No retakes in v1.** The placement runs once per learner.
- If the app is closed mid-test, the learner resumes on the screen they were on. Answers given so
  far are kept.

## 5. What Lucía receives

| Field | From |
|---|---|
| `path` | Q1 |
| `platform` | Q2 |
| `knownWords` | the words tapped in §2 |
| `vocabSection` / vocab band | §2 |
| `grammarRung` | §3 |
| `level` (CEFR, internal) | §2 + §3 |
| `helpLanguage` | always English. **Hebrew is dropped**: Spanish/English only. |

## 6. First call (~10 min, the same plan for everyone)

**Language mix depends on level, with fixed ratios.** At A1 Lucía speaks mostly English and slips in
Spanish words the learner knows. At higher levels she shifts toward Spanish, and B1+ is all Spanish,
with English help only when the learner is stuck. A true beginner (who passed no vocab section)
still gets the call, mostly in English, framed as "your first 5 Spanish phrases".

| # | Step | ~min |
|---|---|---|
| 1 | **Hello:** Lucía introduces herself and asks their name | 1 |
| 2 | **Get to know you:** where you're from, what you do, why Spanish, what you like doing | 4 |
| 3 | **Use your words:** 2–3 sentences built from `knownWords`; the learner repeats or answers | 2 |
| 4 | **3 new words:** from the learner's not-known list, chosen by what they said in step 2 | 2 |
| 5 | **Wrap-up:** recap the 3 new words, praise, "I'll call you tomorrow" | 1 |

Rules for call 1:
- Corrections are gentle: only errors that block meaning are corrected out loud. The live
  underlines still work silently.
- Lucía never says the learner's level.
- **Nothing from the call is saved in v1.** The step-2 answers (job, hobbies, why Spanish) are used
  only during the call itself.

## 7. Data and more languages

The placement content is data, not code, so adding a language means adding rows. No app code
changes.

| File | Tables | Keyed by |
|---|---|---|
| `db/setup-words.sql` | `words` | `language`, `duolingo_section` |
| `db/setup-grammar.sql` | `grammar_rungs` → `grammar_items` → `grammar_options` | `language`, `rung` |

- Every table has a `language` column (ISO 639-1, e.g. `es`). The app reads only the rows for the
  learner's target language.
- Prompts use `___` for the blank. Options are stored in display order with one `is_correct`.
- The ladder's length and the speaking-path start rung come from the data, so another language can
  have a different number of rungs.
- Translations and rung topics are in English, the only help language for now.

## 8. Open questions

- **Word list quality:** the source is community Quizlet sets. Section 1 also contains some
  section 2–3 vocabulary, and section 6 is missing. `difficulty` is the section's approximate CEFR
  band, not a per-word rating.
